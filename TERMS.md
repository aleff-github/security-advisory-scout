# Terms of Service — Security Advisory Scout

Security Advisory Scout provides free, read-only security advisory intelligence for informational and research purposes.

## Service and limitations

The service queries third-party sources including OSV, NVD, FIRST EPSS and CISA KEV. Their records may be revised, incomplete, unavailable, or subject to rate limits. Security Advisory Scout does not guarantee exhaustive vulnerability coverage, accurate version applicability in every environment, a secure configuration, or a finding of compromise.

CVSS severity, FIRST EPSS exploitation probability, CISA KEV evidence, package-version matching and advisory search results must be interpreted separately. Absence of an advisory is not a security guarantee; a vulnerability record by itself does not prove that a host is exploitable or compromised.

The plugin does not scan systems or networks, remediate vulnerabilities, modify repositories, deploy software, or provide incident-response certification or legal advice.

## User responsibilities

Users must validate advisories, affected configurations, vendor fixes, and any production remediation decisions independently. Do not provide confidential credentials, secrets, unnecessary personal information, or private source code in tool inputs. Users are responsible for obtaining necessary permissions for any security work carried out outside the plugin.
